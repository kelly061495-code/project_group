# 會員動態升級規範 Membership Rules

本系統採用「單次註冊，終生累積」的遊戲化升級機制，所有演算與狀態變更發生於使用者完成訂單 (`App.placeOrder`) 及渲染帳號畫面 (`App.renderAccount`) 之際。

## 累積消費計算
- **驅動時機**：使用者點擊「確認下單訂購」。
- **條件**：使用者必須處於登入狀態 (`this.state.user != null`)。
- **寫入邏輯**：
  1. 將該筆訂單之 `Total` (扣除優惠後的實際支付金額) 加入使用者的 `spending` 中。
  2. 立即將更新後的 `spending` 反向寫回 `localStorage` (`trendy_v3_users`)，保護用戶資料不因登出或重整遺失。

## 等級判定與進度計算
- **判定法**：
  1. 引入 `.agent/knowledge/membership.md` 定義之階梯（需陣列反轉 `.reverse()` 或是由後往前查，以找到滿足 `spending >= min` 的「最高階級」）。
  2. 若無，則預設回傳最低等級 (會員 `0`)。
- **進度百分比 (Progress Bar)**：
  - 公式：`( 目前 spending / 下一級 min ) * 100`。
  - 防溢位：使用 `Math.min(100, perc)`，不過通常若算出大於 100 代表已應該進入下一級，但在極限邊界下仍作 `Math.min` 保護。
- **頂峰會員判定**：若當前使用者等級為最高級 (無 `next` 節點)，則進度條消失，換成專屬文字「您已達到最高等級！」。
