# 風格標籤 Style Tags

以下為系統中支援的衣服風格標籤，MCP 智能穿搭推薦引擎將根據這些標籤，結合使用者的 BMI 與即時天氣數據，進行精準的風格與單品匹配。

| 標籤 (En) | 描述 (Zh) | 使用情境 / 推薦法則 |
| --- | --- | --- |
| `Street` | 街頭 | 適合所有日常場合，百搭潮流基礎款。 |
| `Oversized` | 寬鬆 | 炎熱天氣透氣首選；或適合 BMI 較高者修飾身形。 |
| `Dark` | 暗黑 | 適合喜歡前衛、酷黑冷調的消費者。 |
| `Techwear` | 機能風 | 雨天、強風氣候必備，強調防水、多口袋與實用性。 |
| `Cyber` | 賽博 | 強調未來感與前衛特殊剪裁。 |
| `Cargo` | 工裝 | 耐磨硬挺，適合戶外活動或機能穿搭。 |
| `Minimal` | 極簡 | 素面、高質感材質，適合偏好韓系或低調質感者。 |
| `Y2K` | Y2K 復古 | 千禧世代復古潮，如低腰、水洗做舊元素。 |
| `Punk` | 龐克 | 鉚釘、皮衣、金屬風與破壞設計。 |
| `Korean` | 韓系 | 乾淨俐落、合身剪裁，適合 BMI 指數適中偏低者。 |
